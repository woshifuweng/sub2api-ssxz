## 判定规则

- **官方新增**：官方发布说明和上游提交都能对应。
- **SSXZ 定制**：只在我们的定制提交或定制代码中出现。
- **线上历史配置**：线上数据库/渠道能看到，但不能证明是本版本新增。
- **未完成**：代码、页面或线上行为仍缺一层证据。

## 本次审计工程变更

- 客户模型定价页新增“来源”列：官方 v0.2.8、SSXZ 定制、线上已配置、来源待确认；没有线上价格时额外显示“暂无线上定价”。
- 发布预检现在要求候选版本携带 `release-provenance.json`，并检查 `config.yaml`、`data` 链接和 `/login`、`/app/available-channels`、`/model-plaza` 等页面返回 HTML 后才允许切换版本。
- 这些改动已在本地构建和单元测试中验证；本次没有重新发布生产站，因此线上页面不会立即出现“来源”列。

## 线上事实

- 真实用户模型页面是 `/app/available-channels`；`/app/models` 不是项目路由，直接访问 404 属于错误地址，不是线上坏链路。
- `/model-plaza` 是公开模型广场路由，但当前站点开关关闭，访问会按路由守卫返回管理后台；本次没有擅自打开该业务开关。
- 渠道定价页显示 4 个渠道、33 个已定价模型、7 个图片计费模型、待处理提醒 0；图片价格显示 1K/2K 每张 `$0.15`、4K 每张 `$0.30`。

## 禁止误报

没有 Git diff/官方说明和线上行为三层证据时，不得把模型名称写成“本版本新增并生效”。线上看到的模型只能证明当前配置存在，不能反推出来源。
