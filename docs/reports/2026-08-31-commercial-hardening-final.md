# 商业化加固与全站界面验收报告（2026-08-31）

## 结论

本轮候选版本已在隔离预发布环境完成代码、计费与权限回归、备份恢复、全站三档尺寸页面巡检和重点页面人工视觉验收。当前候选版本可进入正式发布审批；本轮没有替换或重启正式站。

## 已完成的产品修复

- 保留 SSXZ 自有界面，只吸收上游 Sub2API 中更完整的能力和信息结构。
- 用户使用记录、API Key、充值、邀请返利和个人资料页面完成桌面、平板与手机适配。
- 管理使用记录、全站 API Key、站点设置与运行监控完成比例、对齐、密度和横向溢出修复。
- 管理顶部在 1024px 宽度下改为紧凑模式，避免文档、语言、用户名和版本信息换行挤压。
- 充值中心在手机和平板改为独立窗口入口，避免验证码被内嵌页面压缩；桌面继续保留内嵌工作台。
- 个人头像改用现有的用户资料更新能力，不再请求已移除的 `/user/avatar` 地址。
- 站点设置隐藏已退役的数据代理入口，TLS 指纹配置改用上游原生、仍受支持的配置管理器。
- 修复 TLS 指纹弹窗首次打开不读取模板的问题，并加入回归测试。
- 运行监控移除上游已删除但旧 SSXZ 页面仍在请求的网关调度器与 OpenAI WS 运行时卡片。
- 图表在窄容器中自动纵向排列，运行日志和告警筛选区在手机和平板不再撑宽整页。
