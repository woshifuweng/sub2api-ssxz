## 正式发布前尚需完成

1. 正式发布授权与独立回退版本确认；不得把执行本地修改当作已正式发布。
2. Linux 隔离数据库升级演练及最新受保护备份，记录结果；不对正式数据库执行试验性回退。
3. 新画布域名配置及精确 CORS 放行。2026-10-02 20:18 只读预检：画布来源 403，现图片工作台来源 204。不能遗漏，也不能改成允许所有来源。
4. 最终安全依赖复验、独立构建、不夹带 localhost/合成数据；保留旧工作台域名与旧静态资源，避免历史丢失和旧标签页 404。
5. 经批准的限额专用测试 Key，真实生成、图片编辑、下载，核对原生用量/扣费和失败不重复扣费；不能用健康检查或本地假接口代替。
6. 逐个发布和验收，保护其他对话完成的文档。任何一项失败，只回退对应应用，不恢复旧数据库覆盖新账务。
